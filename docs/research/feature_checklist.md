## 4. 관리자 기능 (🔵 관리자 계정 확보 후 실측)

팝업 등록/기간(P0), 슬라이더 교체(P0), 회원/그룹 관리·등업 승인(P0), 게시판 생성·권한(P1), 게시글/댓글 관리·스팸(P1)

## 5. 기타

RSS/Atom ✅(P2, 공개 한정) / sitemap ⬜(P1, Next.js 자동 생성) / HTTPS ✅(P0, ACM+ALB)

## 우선순위 요약

- **P0**: 게시판 CRUD+댓글+첨부, 에디터, 인증(이메일 전환), 역할/등업 승인, 팝업 관리, 슬라이더 관리, 최신글 위젯, 반응형, PW 재설정
- **P1**: 캘린더 뷰+위젯, 갤러리 뷰, 통합검색(권한 필터), 공지 고정, 임시저장, 내가 쓴 글, sitemap, 관리자 게시판/게시글 관리
- **P2/제외 후보**: 태그, 신고, 스크랩, 쪽지, SNS 공유, 인쇄, RSS, 비밀글, 추천·카테고리·포인트(미사용)

P2는 조합 운영진과 사용 빈도 확인 후 확정. "단순함 유지" 원칙상 미사용·저빈도 기능은 제외 권고.
