# gforest-web 화면설계서 v1.1 (2026-06-11)

> 기존 사이트 분석(사이트 구조·권한 매트릭스·기능 체크리스트) 기반의 신규 홈페이지 화면설계.
> **마이그레이션 핵심 목적 중 하나인 모바일 UX 개선을 위해 전 화면을 데스크탑(D)/모바일(M) 동시 설계.**
> 근거 문서: `site_structure.md`, `feature_checklist.md`, Confluence 게시판 권한 매트릭스.

## 1. 설계 원칙

1. **모바일 퍼스트**: 학부모 사용자의 주 접속 기기는 스마트폰으로 가정. 모바일 화면을 먼저 설계하고 데스크탑으로 확장
2. **단일 반응형 마크업**: 기존(데스크톱/모바일 별도 마크업) 방식 폐기. 브레이크포인트 — M: ~767px / T: 768~1023px / D: 1024px~
3. **템플릿 최소화**: 게시판 33개가 공통 템플릿 5종(목록/갤러리/캘린더/본문/글쓰기)을 공유. 게시판별 차이는 데이터(boards 테이블)로 처리
4. **권한 주도 UI**: 동일 화면이 역할(익명/일반회원/운영위/교사/학생/관리자)에 따라 메뉴·버튼이 달라짐. 안 보이는 것이 아니라 RLS로 차단된 것을 UI에도 반영
5. **터치 우선 인터랙션**: 탭 타겟 최소 44×44px, 호버 의존 금지(드롭다운 메뉴 → 탭 토글), 스와이프는 보조 수단으로만

## 2. IA (정보구조) — 기존 대비 변경점

```
홈
├─ 학교소개          (정적 페이지 그룹 — 기존 유지)
│   ├─ 교육이념·교사소개 / 교육과정(하위 7) / 조직·운영 / History / 전형안내 / 오시는길
├─ 학교소식          [공개]   알려드립니다 · 학교일정표(캘린더) · 학교이야기 · 교류게시판
│                              · 정보|강좌|좋은글 · 교육자료실 · 살림살이
├─ 커뮤니티          [회원]   자유게시판 · 동호회 · 벼룩시장|부동산 · 도서관
│                              · 방과후 4종(분리 유지 — 확정) · 푸른숲사진첩(갤러리) · 관련사이트
├─ 학부모|학생       [회원]   학부모게시판 · 자료실 3종 · 회의록 · 학생게시판[학생]
├─ 운영위|교사       [회원+]  운영위원회[운영위] · 교사회 5종[교사] · 학부모회 · 요청게시판 2종
│                              · 품의서 · 공간사용예약 · 등업게시판 · 홈피제안
└─ (유틸리티)        로그인/회원가입 · 통합검색 · 마이페이지 · 관리자[admin]
```

- 권한 없는 메뉴는 **미노출** (기존과 동일 정책). 단 회원이 권한 밖 URL 직접 접근 시 명확한 안내 화면(SCR-900)
- 죽은 링크(board_UAoo82) 제거, "전체보기(hot_2024)"는 신규에서 **최신글 통합 피드**로 대체 검토 (P2)
- 모바일 내비게이션: **햄버거 → 풀스크린 드로어** (2뎁스 아코디언). 하단 탭바는 게시판 수가 많아 부적합

## 5. 화면별 설계

### SCR-100 메인

**목적**: 학교 첫인상 + 최신 소식·일정의 허브. 기존 메인의 슬라이더/최신글/일정 구성 계승, 모바일 세로 스크롤 최적화.

데스크탑:
```
┌──────────────────────────────────────────────┐
│ ███████████  슬라이더 (16:6, 자동롤링 5s)  ●●○ │ ①
│              [배너 타이틀 + 내용보기 →]         │
├───────────────────────┬──────────────────────┤
│ 알려드립니다     [+더보기]│  이번 달 일정    [달력→]│ ②③
│ · 공지제목 1      06.10 │  06.12 여가 클래스    │
│ · 공지제목 2      06.09 │  06.15 운영위 회의    │
│ · 공지제목 3      06.08 │  06.20 방학식        │
├───────────────────────┼──────────────────────┤
│ 학교이야기      [+더보기]│ 교류게시판     [+더보기]│ ④
│ · 글제목 …        06.10 │ · 글제목 …      06.10 │
├───────────────────────┴──────────────────────┤
│ [신입·편입 전형안내 배너]  [어린이집] [100주년]    │ ⑤
└──────────────────────────────────────────────┘
```

모바일 (세로 1열 재배치):
```
┌────────────────────────┐
│ ████ 슬라이더(16:9) ●●○ │ ① 스와이프 전환
├────────────────────────┤
│ 알려드립니다      [더보기]│ ② 최근 3건
│ · 공지제목 1            │
├────────────────────────┤
│ 이번 달 일정      [달력→]│ ③ 다가오는 3건
├────────────────────────┤
│ 학교이야기·교류 (탭 전환) │ ④ 탭으로 압축
├────────────────────────┤
│ [전형안내 배너]          │ ⑤
└────────────────────────┘
```

| # | 요소 | 동작/정의 |
|---|---|---|
| ① | 메인 슬라이더 | 관리자 등록 이미지+링크(SCR-602). 자동롤링 5초, M: 스와이프. 이미지 D 1200×450 / M 750×420 별도 크롭 업로드 |
| ② | 공지 위젯 | board_noti 최신 3~5건, 서버 렌더 + 태그 캐시(`unstable_cache`) 10분 |
| ②' | 회원 위젯 (확정) | **로그인 시 자유게시판·학부모게시판 최신글 위젯 추가 노출** — 비로그인에겐 미노출. 회원 위젯 영역은 동적 렌더링(캐시 제외) |
| ③ | 일정 위젯 | 오늘 이후 3~5건. 클릭 → SCR-302 |
| ④ | 최신글 위젯 | D: 2열 병렬, M: 탭 전환으로 높이 절약 |
| ⑤ | 배너 영역 | 전형안내(상시), 외부 링크 |
| — | 레이어 팝업 | SCR-110 — 페이지 위 오버레이 |

**SCR-110 레이어 팝업**: D — 중앙 모달(최대 480px, 복수 시 한 개씩 순차 표시). **M — 하단 시트(bottom sheet)**로 표시해 화면 전체를 가리지 않음. 닫기 옵션 "오늘 하루 보지 않기 / N일 보지 않기"(localStorage). 관리자가 기간·재노출 주기 설정(SCR-601). *기존 모바일에서 드래그 팝업이 화면을 가리던 문제의 직접 개선.*

### SCR-200 정적 페이지

```
D: [좌측 서브메뉴 220px | 본문 (제목 + 콘텐츠)]      M: [상단 가로스크롤 칩 서브메뉴]
                                                      [본문 1열]
```
- 13개 페이지 공통. 콘텐츠는 마이그레이션 시 HTML 정리 후 MDX/DB 저장 (관리자 수정 가능 여부는 P1 결정)
- M: 좌측 메뉴 대신 **가로 스크롤 칩**(현재 페이지 강조) — 세로 공간 확보
- 오시는길: 지도 임베드(카카오/네이버), M에서 "길찾기 앱 열기" 버튼

### SCR-300 게시판 목록 (목록형 공통 — 28개 게시판)

데스크탑:
```
┌──────────────────────────────────────────────┐
│ 게시판명               [검색: 제목+내용 ▾] [🔍] │ ①②
├──────────────────────────────────────────────┤
│ 📌 공지 | 고정 공지 제목                  06.01 │ ③
│ 제목 (댓글수)                작성자  06.10  👁N │ ④
│ 제목 📎                      작성자  06.09  👁N │
│ …                                            │
├──────────────────────────────────────────────┤
│            ◀ 1 2 3 … 10 ▶          [글쓰기]  │ ⑤⑥
└──────────────────────────────────────────────┘
```

모바일 (테이블 → 카드 리스트):
```
┌────────────────────────┐
│ 게시판명          [🔍]  │
├────────────────────────┤
│ 📌 고정 공지 제목        │
├────────────────────────┤
│ 제목이 두 줄까지 표시…    │ ← 행 전체 탭 영역
│ 작성자 · 06.10 · 💬3 📎 │   (최소 높이 64px)
├────────────────────────┤
│ …                      │
│   [더 불러오기 / 무한스크롤]│ ⑤
└────────────────────────┘
                    (FAB) ✏️ ← ⑥ 쓰기 권한자만
```

| # | 요소 | 정의 |
|---|---|---|
| ① | 게시판 헤더 | boards 테이블의 이름·설명. 권한 게시판은 자물쇠 아이콘 표기 |
| ② | 검색 | 제목/내용/작성자 범위 선택. M: 아이콘 탭 → 검색바 확장 |
| ③ | 고정 공지 | 운영진 글 고정(P1). 목록 상단 분리 |
| ④ | 목록 행 | D: 테이블(제목/작성자/날짜/조회) · M: 2줄 카드(제목+메타). 첨부📎·댓글수💬 뱃지 |
| ⑤ | 페이징 | D: 페이지 번호 · M: 무한스크롤+위치 복원 (뒤로가기 시 스크롤 유지 필수) |
| ⑥ | 글쓰기 | D: 우하단 버튼 · M: FAB(고정). write_role 충족 시만 노출 |

상태: 빈 게시판("아직 게시글이 없습니다 + 첫 글 쓰기 유도"), 로딩 스켈레톤, 검색 결과 0건.

### SCR-301 갤러리형 (푸른숲사진첩)

```
D: 4열 썸네일 그리드 (1:1 크롭, 제목+날짜 오버레이)
M: 2열 그리드, 무한스크롤
```
- 본문은 SCR-310 공통 사용 + 본문 내 이미지 라이트박스(스와이프 넘김)
- 업로드 시 클라이언트 리사이즈(장변 1600px) — Storage 1GB 보호 정책과 연동

### SCR-302 학교일정표 (캘린더)

데스크탑: 월 그리드(일정 제목 인라인 표시) + 우측 선택일 상세 패널.
모바일:
```
┌────────────────────────┐
│ ◀ 2026년 6월 ▶  [월|목록]│ ① 뷰 전환
│ 일 월 화 수 목 금 토      │
│ … 캘린더 그리드(점 표시)…│ ② 일정 있는 날 = 도트
├────────────────────────┤
│ 6월 12일 (금)            │ ③ 선택일 일정 리스트
│ · 여가 클래스 14:00      │   (탭하면 본문)
└────────────────────────┘
```
- M 기본은 **월 그리드(도트) + 하단 선택일 리스트** 조합 — 기존 모바일에서 월 표가 깨지던 문제 개선. [목록] 뷰는 다가오는 일정 시간순
- 일정 등록은 글쓰기(SCR-320)에 날짜 필드 추가된 변형. 데이터는 posts + event_date 컬럼

### SCR-303 공간사용예약 (예약 캘린더 — 확정: 게시판 → 캘린더 UI 개선)

```
M:
┌────────────────────────┐
│ 공간: [전체 ▾]           │ ① 공간 필터 (강당/교실/…)
│ ◀ 6월 ▶  (도트 캘린더)   │ ② 예약 있는 날 = 공간색 도트
├────────────────────────┤
│ 6월 12일 (금)            │ ③ 선택일 예약 현황
│ · 14~16시 강당 | ○○동호회 │
│ [+ 이 날짜에 예약하기]    │ ④ 예약 등록(회원)
└────────────────────────┘
```
- SCR-302 캘린더 컴포넌트 재사용 + 공간 필터·시간대 필드 추가
- 예약 등록: 날짜·시작/종료 시간·공간 선택·사유 — **시간대 중복 시 등록 차단 + 기존 예약 표시**
- 데이터: posts 확장(공간 ID, 시작/종료 시각). 기존 게시판 데이터는 그대로 이관 후 신규 등록부터 구조화
- 권한: 기존과 동일(회원 읽기/쓰기). 취소는 본인+관리자

### SCR-310 게시글 본문

```
D/M 공통 구조 (M은 1열):
┌────────────────────────┐
│ ← 목록            ⋯메뉴 │ ① (수정/삭제/신고 — 권한별)
│ 제목                    │
│ 작성자 · 06.10 · 조회 N  │
├────────────────────────┤
│ 본문 (이미지 반응형)      │ ②
│ 📎 첨부파일 n개 [다운로드] │ ③
├────────────────────────┤
│ 💬 댓글 N               │ ④
│ │ 댓글 … [답글]          │   1단계 대댓글
│ │  └ 대댓글 …            │
│ [댓글 입력란______] [등록]│ ⑤
├────────────────────────┤
│ ◀ 이전글 | 다음글 ▶      │ ⑥
└────────────────────────┘
```

| # | 요소 | 정의 |
|---|---|---|
| ① | 액션 메뉴 | 본인 글: 수정/삭제. 관리자: +고정/이동. M: ⋯ 바텀시트 |
| ② | 본문 | XE 이관 콘텐츠 포함 이미지 max-width 100% 강제 — *기존 모바일 가로 스크롤 문제 해결* |
| ③ | 첨부 | 권한 게시판 파일은 서명 URL. 이미지 첨부는 본문 하단 갤러리 표시 |
| ④ | 댓글 | 1단계 대댓글. 본인 댓글 수정/삭제 |
| ⑤ | 댓글 입력 | 회원만. M: 하단 고정 입력바(키보드 대응 safe-area) |
| ⑥ | 이전/다음 | 같은 게시판 내 이동 |

### SCR-320 글쓰기/수정

```
M 기준 (D는 max-width 800px 동일 구조):
┌────────────────────────┐
│ ✕ 취소    글쓰기   [등록] │ ① 상단 고정바
│ [제목 입력_____________] │
│ ┌ 에디터 툴바(최소화) ──┐ │ ② B/I/링크/이미지/목록
│ │ 본문 작성 영역        │ │
│ └─────────────────────┘ │
│ 📎 파일 첨부 [+]         │ ③ 카메라/앨범/파일
│ (일정 게시판: 날짜 선택)  │ ④ 캘린더 변형
└────────────────────────┘
```
- 에디터: 경량 WYSIWYG(Tiptap 등). **모바일에서 이미지 첨부 = 카메라/앨범 직접 호출** — 기존 CKEditor 모바일 UX의 최대 개선점
- 이미지 업로드 시 클라이언트 리사이즈 + 진행률 표시. 임시저장(P1): 자동 로컬 저장 + 이탈 경고
- 등록 실패(네트워크) 시 작성 내용 보존 필수

### SCR-400/401/402 로그인 · 회원가입 · 비밀번호 재설정

- 로그인: 이메일+비밀번호 단일 폼. **기존 아이디 로그인 → 이메일 전환 안내 문구 상시 노출**("기존 회원은 가입 시 등록한 이메일로 로그인하세요. 비밀번호는 재설정이 필요합니다")
- 회원가입: 이메일/비밀번호/이름/닉네임(필수), 가입 후 안내 화면 — "운영진 승인(등업) 후 회원 게시판 이용 가능" 명시. *기존 등업게시판 글쓰기 방식을 가입 플로우에 내장하여 대체*
- 재설정: 이메일 입력 → 메일 발송 → 새 비밀번호 설정. 마이그레이션 직후 대량 사용되는 화면이므로 문구를 이관 안내와 통합
- M: 모든 입력 1열, 키보드 타입 지정(이메일 자판), 비밀번호 보기 토글

### SCR-410 마이페이지

탭 구조: **프로필**(닉네임/사진 수정, 이메일 표시) / **내가 쓴 글** / **내 댓글**. 역할 뱃지(일반회원/운영위 등) 표시. 등업 신청 상태(대기 중) 노출.

### SCR-500 통합검색

- 헤더 검색 → 결과: 게시판별 그룹핑, **RLS에 의해 내 권한으로 읽을 수 있는 글만** 결과에 포함 (권한 필터가 설계 핵심)
- M: 검색 전용 풀스크린 (최근 검색어 로컬 저장)

### SCR-600~603 관리자

별도 `/admin` 영역 (admin 역할만, GNB와 분리된 단순 레이아웃):

| 화면 | 핵심 기능 |
|---|---|
| SCR-600 회원·역할 | 회원 목록(검색/필터), **역할 변경 드롭다운**(member/operator/teacher/student/admin), 신규 가입 승인 대기 목록 — *기존 등업게시판 워크플로 대체* |
| SCR-601 팝업 관리 | 팝업 목록/등록(제목·내용·이미지·링크·게시 기간·재노출 주기 N일·노출 순서)·미리보기(D 모달/M 바텀시트) |
| SCR-602 슬라이더 관리 | 슬라이드 목록(드래그 정렬)·등록(D/M 이미지 각 1장, 링크, 활성 여부) |
| SCR-603 게시판 관리 | boards 테이블 CRUD: 이름·슬러그·메뉴 위치·read_role/write_role·형식(목록/갤러리/캘린더/예약) |
| SCR-604 정적 페이지 편집 (확정) | 학교소개 13개 페이지 목록 → 본문 에디터(SCR-320과 동일 에디터 재사용) 수정·발행. 수정 이력(P2) |

- 관리자 화면도 모바일 대응(운영진이 폰으로 승인 처리하는 시나리오) — 단 표 위주라 가로 스크롤 허용

### SCR-900 권한 안내 / 404

- 비로그인 + 회원 전용 → "로그인이 필요합니다" + 로그인 버튼(returnTo 유지)
- 로그인 + 권한 부족 → "이 게시판은 ○○ 권한이 필요합니다" (어떤 권한인지 명시 — 기존 'OOPS!' 화면보다 행동 가능하게)
- 404: 홈/검색 유도

## 6. 모바일 UX 개선 요약 (기존 → 신규)

| 기존 문제 | 신규 설계 |
|---|---|
| 데스크톱/모바일 별도 마크업, 모바일 화면 깨짐 | 단일 반응형, 모바일 퍼스트 |

| CKEditor 모바일 작성 불편 | 경량 에디터 + 카메라/앨범 직접 첨부 |
| 월 캘린더 표가 모바일에서 깨짐 | 도트 그리드 + 선택일 리스트 |
